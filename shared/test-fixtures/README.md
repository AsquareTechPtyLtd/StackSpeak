# Cross-platform golden fixtures

These JSON files are the **executable contract** for cross-platform parity. iOS
generates them from production code; Android (and any future client) must
reproduce the same values byte/semantic-exact. They guard the determinism-critical
pieces in `.planning/android-app-plan-2026-06-14.md` §Part 1.

## Source of truth & regeneration

Generated by `ios/StackSpeakTests/Fixtures/FixtureGenerationTests.swift` from the
live iOS code (no hand-authored values). The same test **validates** on every run:
it recomputes from production code and asserts the committed bytes still match, so
any drift in a determinism-critical path fails CI.

To regenerate intentionally (after a deliberate contract change):

```bash
# delete the file(s) you want rebuilt, or force all:
GENERATE_FIXTURES=1 xcodebuild test \
  -project ios/StackSpeak.xcodeproj -scheme StackSpeak \
  -destination 'platform=iOS Simulator,name=iPhone 16 Pro' \
  -only-testing:StackSpeakTests/FixtureGenerationTests
```

Then review the diff — a changed fixture means the cross-platform contract moved
and Android must be updated in lockstep (bump `ProgressSnapshot.schemaVersion` if
the snapshot shape changed).

## Contract notes (parity gotchas)

- **Dates:** ISO-8601, **no fractional seconds**, `Z` suffix (e.g.
  `2026-01-01T00:00:00Z`). This is the backend's real `JSONEncoder.dateEncodingStrategy = .iso8601`
  output. (The plan earlier *guessed* fractional seconds — the fixtures are authoritative.)
- **UUID strings are UPPERCASE** (Swift `.uuidString`). Kotlin's `UUID.toString()`
  is lowercase — Android **must uppercase** every id before serializing or comparing.
- **Nil optionals are omitted keys, not `null`** (Swift `encodeIfPresent`). See
  `snapshots/nil-optionals.json`: `lastCompletedDate`, a review's `lastReviewedAt`,
  and a book's `currentChapterId`/`currentCardId` are simply absent. Android:
  `Json { explicitNulls = false }`.
- **u64 values are decimal strings** (`stableHash`, RNG outputs) — JSON numbers
  can't hold a u64. Kotlin reads them as `ULong`.
- **deterministicUUID sets no RFC version/variant bits** — it's a raw 128-bit value.
- The committed files use sorted keys + pretty-print for clean diffs; **key order
  is not a functional requirement** (the wire format the app pushes is compact).

the documented inputs, and assert equality against the expected outputs.
